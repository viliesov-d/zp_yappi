# Зміна — калькулятор зарплати для графіка 4/2

Готовий україномовний адаптивний сайт, який працює без сервера, збірки та сторонніх бібліотек.

## Запуск

1. Розпакуйте архів.
2. Відкрийте `index.html` у сучасному браузері. Або відкрийте `standalone.html` — повністю автономну односторінкову версію без окремих файлів.
3. Для публікації завантажте всю папку на статичний хостинг (GitHub Pages, Netlify, Vercel тощо).

## Як працює графік 4/2

У блоці **Графік 4/2** виберіть опорну дату (день, статус якого ви точно знаєте) та позицію цього дня у шестиденному циклі:

- 1–4: робочі дні;
- 5–6: вихідні.

Графік автоматично продовжується на попередні й наступні місяці незалежно від днів тижня. При зміні опорної дати вже записані суми та ручні статуси не видаляються. Заробіток у датах, які стали неробочими за новим графіком, не враховується доти, доки дата не стане робочою або заміною.

## Редагування дня

Натисніть на дату в календарі:

- **За графіком** — автоматично робочий або вихідний день; у робочий день можна записати заробіток.
- **За свій рахунок** — день без оплати; раніше записаний заробіток не враховується у підсумках, але зберігається на випадок повернення статусу.
- **Вийшла на заміну** — додаткова робоча зміна з введенням заробітку.
- **Очистити день** — повністю скидає ручний статус, примітку та суму.

Грошові суми записуються в копійках, щоб уникнути похибок під час додавання.

## Зарплата за періоди

- Весь заробіток **з 1 по 15 число** обраного місяця — **зарплата 25 числа цього ж місяця**.
- Весь заробіток **з 16 по останнє число** обраного місяця — **зарплата 10 числа наступного місяця**.
- **10 числа на календарі** показується сума за 16–кінець **попереднього** місяця.
- **25 числа на календарі** показується сума за 1–15 **поточного** місяця.
- Враховуються лише суми, фактично внесені користувачем у робочі зміни або заміни. Автоматичних ставок, податків чи надбавок немає.

## Зберігання даних

Використовується `localStorage` у браузері, ключ: `zminaSalaryCalendarV1`. Збереження має обробку помилок. Для перенесення чи резервування даних є кнопки **Експорт JSON** / **Імпорт**. Імпорт замінює всі поточні записи після підтвердження.

**Важливо:** це локальна версія без реєстрації/облікових записів та хмарної синхронізації. Дані не передаються на сервер і можуть зникнути, якщо очистити дані сайту. Для справжньої реєстрації та синхронізації між пристроями потрібен бекенд (наприклад, Supabase або Firebase).

## Структура

- `index.html` — сторінка та доступні форми;
- `styles.css` — адаптивний дизайн;
- `logic.js` — обчислення графіка, дат і зарплат;
- `app.js` — інтерфейс та локальне сховище;
- `favicon.svg` — значок сайту.

- `standalone.html` — та сама програма в одному HTML-файлі.
